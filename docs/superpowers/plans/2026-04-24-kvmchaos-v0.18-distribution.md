# kvmchaos v0.18 — Distribution (Binary RPM) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a self-contained binary RPM that installs kvmchaos on an air-gapped RHEL 9 KVM host with no Python dependency.

**Architecture:** PyInstaller bundles the Python runtime + all deps into a single executable built inside an AlmaLinux 9 CI container (RHEL 9 ABI, glibc 2.34). rpmbuild packages the binary + bash completion into an RPM. A new `build-rpm` GitHub Actions job uploads the RPM to the GitHub Release alongside the existing wheel.

**Tech Stack:** PyInstaller 6+, rpmbuild (rpm-build package), AlmaLinux 9 container, GitHub Actions

### Task 3: RPM spec

**Files:**
- Create: `packaging/kvmchaos.spec`

No `%build` section — the binary is pre-built by PyInstaller before `rpmbuild` runs. `%install` copies the pre-built files from `%{SOURCE0}` / `%{SOURCE1}` (i.e., `~/rpmbuild/SOURCES/`) into the buildroot. The only runtime dependency declared is `libvirt-libs` — already present on any KVM host.

- [ ] **Step 1: Create packaging/kvmchaos.spec**

```spec
Name:           kvmchaos
Version:        0.18.0
Release:        1%{?dist}
Summary:        KVM chaos engineering CLI
License:        MIT
BuildArch:      x86_64

Source0:        kvmchaos
Source1:        kvmchaos-bash-completion

Requires:       libvirt-libs

%description
kvmchaos injects and reverts KVM faults (vm.pause, net.latency, disk.latency,
clock.skew, and others) against KVM VMs via libvirt. Supports declarative
multi-step experiments, structured JSON event logging, safety allowlist,
and rate limiting. Targets RHEL 9 KVM hosts.

%install
install -Dm755 %{SOURCE0} %{buildroot}%{_bindir}/kvmchaos
install -Dm644 %{SOURCE1} %{buildroot}%{_sysconfdir}/bash_completion.d/kvmchaos

%files
%{_bindir}/kvmchaos
%{_sysconfdir}/bash_completion.d/kvmchaos

%changelog
* Thu Apr 24 2026 Vadym Herman <vadymherman@gmail.com> - 0.18.0-1
- Initial RPM packaging with self-contained PyInstaller binary.
```

### Task 4: build.sh

**Files:**
- Create: `packaging/build.sh`

This script runs on AlmaLinux 9 (in CI or locally in an equivalent container). Prerequisites: `uv` on PATH (with pyinstaller in the venv via `uv sync`), `rpmbuild` on PATH. The script is self-contained — it sets up the `~/rpmbuild/` tree itself.

- [ ] **Step 1: Create packaging/build.sh**

```bash
#!/usr/bin/env bash
set -euo pipefail

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "$REPO_ROOT"

# Build self-contained binary
uv run pyinstaller \
  --onefile \
  --name kvmchaos \
  --collect-all kvmchaos \
  --hidden-import=libvirt \
  --distpath dist/ \
  packaging/entrypoint.py

# Generate bash completion from the just-built binary
./dist/kvmchaos --show-completion bash > packaging/kvmchaos-bash-completion

# Set up rpmbuild directory tree
mkdir -p ~/rpmbuild/{BUILD,RPMS,SOURCES,SPECS,SRPMS}
cp dist/kvmchaos                       ~/rpmbuild/SOURCES/kvmchaos
cp packaging/kvmchaos-bash-completion  ~/rpmbuild/SOURCES/kvmchaos-bash-completion
cp packaging/kvmchaos.spec             ~/rpmbuild/SPECS/kvmchaos.spec

# Build RPM
rpmbuild -bb ~/rpmbuild/SPECS/kvmchaos.spec

RPM=$(ls ~/rpmbuild/RPMS/x86_64/kvmchaos-*.rpm)
echo "Built: $RPM"
```

### Task 5: CI — build-rpm job

**Files:**
- Modify: `.github/workflows/release.yml`

The existing workflow has two jobs: `build` (builds sdist+wheel, uploads artifact) and `github-release` (creates the GitHub Release, attaches wheel). Add a third job `build-rpm` that runs after `github-release` so the release already exists when the RPM is uploaded. `softprops/action-gh-release@v2` will append the RPM file to the existing release.

- [ ] **Step 1: Append build-rpm job to release.yml**

Add the following after the last line of `.github/workflows/release.yml`:

```yaml

  build-rpm:
    needs: github-release
    runs-on: ubuntu-latest
    container: almalinux:9
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4

      - name: Install build tools
        run: |
          dnf install -y python3.11 python3.11-pip rpm-build libvirt-devel pkg-config
          pip3.11 install uv

      - name: Install project dependencies
        run: uv sync --python python3.11

      - name: Build RPM
        run: |
          bash packaging/build.sh
          mkdir -p "$GITHUB_WORKSPACE/dist-rpm"
          cp ~/rpmbuild/RPMS/x86_64/kvmchaos-*.rpm "$GITHUB_WORKSPACE/dist-rpm/"

      - name: Upload RPM to release
        uses: softprops/action-gh-release@v2
        with:
          files: dist-rpm/kvmchaos-*.rpm
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
