# kvmchaos v0.20 — SSH Removal & Structural Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove SSH support (breaking change); fix `disk.fill` inject cleanup; add cooperative `KeyboardInterrupt` cancellation; refactor `_StepOutcome`/`_collect_parallel_batch` to `experiment.py`; rename `safety.py` → `prompts.py`; add `--max-workers` flag.

**Architecture:** SSH (`qemu+ssh://`) is removed because `net.*`/`disk.*` faults require local execution, making the half-support dishonest. The `local_only` ClassVar and `_is_remote()` function disappear entirely; a new guard in `_root` rejects `qemu+ssh://` URIs with a clear error. Concurrency improvements (threading.Event) live in `cli.py` for now — the runner is not fully decoupled because it is entangled with `typer.echo`/`typer.Exit` calls, which belong in v0.21's larger runner-extraction refactor.

**Tech Stack:** Python 3.11+, libvirt-python, typer, stdlib `threading`, `functools`, `pytest`.

## Task 3: Fix `disk.fill` inject cleanup on failure (H3)

**Files:**
- Modify: `src/kvmchaos/faults/disk_fill.py`
- Modify: `tests/test_disk_fill.py`

The bug: if `fallocate` or `dd` raises mid-run, the partially-allocated file is never cleaned up. `revert` calls `fill.unlink(missing_ok=True)`, but `revert` is only called explicitly by the runner on verify-fail or after hold — not on inject-fail.

The fix: `inject` cleans up the fill file itself if the subprocess call fails.

```python
    domain = MagicMock(spec=libvirt.virDomain)
    domain.name.return_value = "server1"
    # Fake a domain XML with a temp image file
    image = tmp_path / "server1.qcow2"
    image.touch()

        f"<domain><devices><disk device='disk'>"
```

```python
    def inject(self, domain: libvirt.virDomain) -> None:
        """Create a preallocated fill file next to the VM's disk image.
        ...
        """
        image = _image_path(domain)
        free = shutil.disk_usage(image.parent).free
        if self.fill_bytes > int(free * 0.8):
            raise RuntimeError(
                f"insufficient disk space for disk.fill on '{domain.name()}': "
                f"requested {self.fill_bytes} bytes but only {free} bytes free "
                f"(limit is 80% of free space)"
            )
        fill = _fill_path(image, domain.name())
        try:
            subprocess.run(
                ["fallocate", "-l", str(self.fill_bytes), str(fill)],
                check=True,
                capture_output=True,
            )
        except FileNotFoundError:
            try:
                subprocess.run(
                    [
                        "dd",
                        "if=/dev/zero",
                        f"of={fill}",
                        "bs=1M",
                        f"count={max(1, self.fill_bytes // (1024 * 1024))}",
                    ],
                    check=True,
                    capture_output=True,
                )
            except subprocess.CalledProcessError as exc:
                fill.unlink(missing_ok=True)
                raise RuntimeError(f"disk.fill inject failed for {domain.name()}: {exc}") from exc
        except subprocess.CalledProcessError as exc:
            fill.unlink(missing_ok=True)
            raise RuntimeError(f"disk.fill inject failed for {domain.name()}: {exc}") from exc
```

```python
from dataclasses import dataclass, field as _field


@dataclass
class _StepOutcome:
    """Result of executing a single experiment step on one VM."""

    vm: str
    success: bool
    exit_code: int = 0


def _collect_parallel_batch(steps: list[Step], start: int) -> list[tuple[int, Step]]:
    """Return contiguous (original_index, step) pairs starting at ``start`` while parallel=True.

    Returns an empty list if ``steps[start].parallel`` is False. A single step
    with ``parallel=True`` but no adjacent parallel neighbours returns a list of
    length 1; the caller treats that the same as a non-parallel step
    (``len(batch) >= 2`` guard).

    Args:
        steps: Full ordered list of experiment steps.
        start: Index of the first step to check.

    Returns:
        List of ``(original_index, step)`` pairs for the parallel batch.
    """
    pairs: list[tuple[int, Step]] = []
    j = start
    while j < len(steps) and steps[j].parallel:
        pairs.append((j, steps[j]))
        j += 1
    return pairs
```

## Task 6: Cooperative `KeyboardInterrupt` cancellation via `threading.Event` (H2)

**Files:**
- Modify: `src/kvmchaos/cli.py` — `_run_experiment_step` + `_run_experiment_step_on_vm`
- Modify: `tests/test_experiment.py` or a new `tests/test_cancellation.py`

The bug: Ctrl-C during a parallel hold is delivered to the main thread only; worker threads keep sleeping until `step.duration` elapses, leaving faults active on sibling VMs.

The fix: pass a `threading.Event` (the "stop event") down to each worker. Workers poll it inside the hold sleep; when set they skip the remaining sleep and proceed to revert. The main thread sets the event on `KeyboardInterrupt`.

- [ ] **Step 1: Write a failing test**

Add to `tests/test_experiment.py` (or a new `tests/test_cli_cancellation.py`):

```python
import threading
import time
from unittest.mock import MagicMock, patch
import libvirt

def test_stop_event_interrupts_hold(tmp_path):
    """Worker must exit the hold early when the stop event is set."""
    from kvmchaos.cli import _run_experiment_step_on_vm
    from kvmchaos.experiment import Step

    stop = threading.Event()
    step = Step(fault="vm.pause", vm="server1", duration=60)

    # Fake libvirt connect + domain
    conn = MagicMock()
    domain = MagicMock(spec=libvirt.virDomain)
    domain.name.return_value = "server1"
    domain.state.return_value = (libvirt.VIR_DOMAIN_PAUSED, 0)

    def fake_connect(*args, **kwargs):
        from contextlib import contextmanager
        @contextmanager
        def _ctx():
            yield conn
        return _ctx()

    conn.__enter__ = lambda s: conn
    conn.__exit__ = MagicMock(return_value=False)
    conn.lookupByName.return_value = domain

    # Set stop event after 0.1s — hold should abort well before 60s
    threading.Timer(0.1, stop.set).start()
    t0 = time.monotonic()
    with patch("kvmchaos.cli.connect", return_value=conn):
        outcome = _run_experiment_step_on_vm(
            step, "server1",
            resolved_uri="test:///default",
            dry_run=False,
            config_path=None,
            force=True,
            stop_event=stop,
        )
    elapsed = time.monotonic() - t0
    assert elapsed < 5, f"hold was not interrupted (took {elapsed:.1f}s)"
    # Revert must still have been called
    domain.resume.assert_called()
```

```python
def _run_experiment_step(
    step: Step,
    *,
    resolved_uri: str,
    dry_run: bool,
    config_path: Path | None,
    force: bool,
    max_workers: int = 8,
) -> list[_StepOutcome]:
    """Fan out step across all target VMs, executing in parallel."""
    stop_event = threading.Event()
    worker = functools.partial(
        _run_experiment_step_on_vm,
        step,
        resolved_uri=resolved_uri,
        dry_run=dry_run,
        config_path=config_path,
        force=force,
        stop_event=stop_event,
    )
    with ThreadPoolExecutor(max_workers=min(len(step.vms), max_workers)) as pool:
        return list(pool.map(worker, step.vms))
```
